# デジタル庁 DS-455（GIF 実装データモデル 防災）および 内閣府 EEI とのフィットギャップ分析

## 1. 概要と背景

### 1.1 背景

デジタル庁では、政府情報システムや官民のデータ連携を円滑にするため「政府相互運用性フレームワーク（GIF: Government Interoperability Framework）」を策定しています。このうち防災分野に該当するのが **「455_実装データモデル_防災」** です。
このモデルは、内閣府が策定・運用を進めている **「災害対応基本共有情報（EEI: Essential Elements of Information）」**（第1.1版：99項目、約1,300属性）を技術的なクラス図・データ構造として標準化したものです。

将来的な **防災庁** の設置や、国（新総合防災情報システム SOBO-WEB / SIP4D）と地方自治体、指定公共機関、民間防災サービス間のデータ自動流通の基盤となることが見込まれています。

### 1.2 本分析の目的

現時点において国・自治体側で DS-455 に準拠したリアルタイムなデータ受信・フィード先システムが一般開放されているわけではありません。そのため、**即座の実装は行わず、将来の防災庁発足やEEI実装の具体化に備え、tossa の現行 GeoJSON フィード（`/api/feed.json`）とのフィットギャップおよび将来の拡張方針を整理・保存すること** を目的とします。

## 2. tossa 現行データ構造と DS-455 / EEI の対比

### 2.1 関連する GIF 455 クラスモデル

tossa のような地域生活・避難支援プラットフォームに直接関わる主要モデルは以下の3点です：

1. **`455-1-21_避難所等データモデル`**（指定避難所・福祉避難所・開設状況・受入能力）
2. **`455-1-12_水道データモデル`**（応急給水所・断水状況・持参要件）
3. **`455-1-11_物資データモデル`**（支援物資集積所・配布品目・在庫状況）

### 2.2 フィットギャップ詳細

| 評価軸             | tossa 現行仕様 (`/api/feed.json`)                                               | DS-455 (GIF 455 / EEI) 標準                                                                                  | ギャップ内容と評価                                                                                                                                       |
| :----------------- | :------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **空間表現**       | GeoJSON `geometry.coordinates`: `[lng, lat]` (WGS84)                            | GeoJSON / WGS84 準拠                                                                                         | **完全合致（Gapなし）**。<br>国際標準の経度・緯度順を採用済み。                                                                                          |
| **時間表現**       | ISO 8601 UTC (`2026-09-17T...Z`)                                                | ISO 8601 UTC                                                                                                 | **完全合致（Gapなし）**。<br>更新履歴 (`statusHistory`) もISO 8601。                                                                                     |
| **施設識別子**     | `id`: `"post_178..."` (tossa独自ID)                                             | 内閣府「全国共通避難所・避難場所ID」<br>(例: `43100-0012`)                                                   | **受皿の確保が必要**。<br>現在は自治体オープンデータを取り込んでいないため独自IDのみ。将来的に `shelterId` / `nationalFacilityId` の属性スロットが必要。 |
| **ステータス体系** | `currentStatus`: `"available"` / `"crowded"` / `"closed"`                       | **開設状況** (`openStatus`: 開設/閉鎖/準備中) と **受入状況** (`capacityStatus`: 受入可/混雑/満員) の2軸分離 | **概念の集約がGap**。<br>tossaは住民向けの直感的UIとして「利用可能/混雑/終了」に集約。機械連携時は2軸に分解して出力するのが望ましい。                    |
| **設備・受入要件** | `tags` や `attributes` の自由形式<br>(例: `["給水", "車椅子対応", "ペット可"]`) | `barrier_free: boolean`<br>`pets_allowed: boolean`<br>`has_power: boolean`<br>`has_water: boolean`           | **構造化の度合いがGap**。<br>tossaはボキャブラリの自発的成長を優先しているため、機械連携時にはタグから boolean フラグへの正規化マッピングが必要。        |
| **給水所要件**     | `note` や `attributes`                                                          | 給水稼働状況、**容器持参要否** (`containerRequired`)、1人あたり配給制限                                      | **給水所特有フラグが未正規化**。<br>「ポリタンク持参要」などの頻出要件を構造化属性として扱う余地あり。                                                   |
| **情報信頼度**     | `isVerified: 1`, `verificationCount: 3`, `sourceUrl`                            | 発信元区分（公的/管理者/住民）、**C2PA暗号署名有無**                                                         | **tossaが先行**。<br>tossaはC2PA真正性署名やコミュニティ現地確認（👍）を実装しており、EEI標準に対しても高い信頼性メタデータを提供可能。                  |

## 3. 将来的な GeoJSON 拡張プロパティ設計案

防災庁や自治体側のシステムが整備された際、既存の tossa クライアントとの**下位互換性を100%維持**したまま、エクスポート時に付与すべき拡張プロパティの仕様案です。

```jsonc
{
  "type": "Feature",
  "id": "post_1789608771107_rs7ss",
  "geometry": {
    "type": "Point",
    "coordinates": [130.707, 32.799], // [経度, 緯度]
  },
  "properties": {
    // --- 既存 tossa プロパティ（下位互換維持） ---
    "title": "中央小学校 体育館",
    "area": "中央区本町",
    "address": "熊本市中央区本町1-1",
    "currentStatus": "available",
    "statusLabel": "開設中・受入可",
    "tags": ["避難所", "給水", "車椅子対応", "ペット可"],
    "verificationCount": 3,
    "lastVerifiedAt": "2026-09-17T08:00:00Z",

    // --- DS-455 (GIF 455 / EEI) 将来拡張項目 ---
    "eei": {
      "facilityType": "shelter", // 避難所: shelter / 給水所: water / 支援拠点: supplies
      "shelterId": "43100-0012", // 全国共通避難所・避難場所ID（付番されている場合）
      "openStatus": "open", // "open" (開設) | "standby" (準備中) | "closed" (閉鎖)
      "capacityStatus": "available", // "available" (受入可) | "crowded" (混雑) | "full" (満員)
      "capabilities": {
        "barrierFree": true, // バリアフリー / 車椅子 / 要配慮者受入
        "petsAllowed": true, // ペット同行受入可
        "hasWater": true, // 応急給水・水利用可
        "hasPower": false, // 非常用電源・充電可
        "hasWifi": false, // 00000JAPAN等のWi-Fi開設
      },
      "waterSupply": {
        "supplyActive": true, // 給水稼働中
        "containerRequired": true, // ポリタンク等の容器持参が必要
      },
      "provenance": {
        "sourceType": "citizen_verified", // official (公的) | manager (管理者) | citizen_verified (住民確認)
        "c2paVerified": true, // C2PA 暗号署名による画像・データ真正性確認済
      },
    },
  },
}
```
